# ThermoBase v19 — The Scientific Story

This is a storytelling-first GitHub Pages prototype based on the completed ThermoBase analytical work.

## Narrative
1. Observe the source population
2. Rehabilitate physiological evidence
3. Separate phylogenetic structure from ecological/metabolic association
4. Stress-test environmental ML predictions against lineage shortcuts
5. Apply the resulting framework to planetary regimes
6. Use Enceladus as the reaction-context / abiotic-baseline test case
7. Hand the reader back to the full evidence layer

## Important
This prototype intentionally uses verified aggregate results from the frozen analytical work. It is a narrative layer, not a replacement for the full 337-field record explorer. The full record-level JSON should be attached to the release when the canonical v18 data artifact is available in the repository.
