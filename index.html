MACHINE LEARNING

Can environment predict metabolism?

The primary ML question is environmental–metabolic coupling. Random cross-validation is only the first test.

↳
The important comparison is not “who wins?”

Environment-only performance asks whether the physical setting carries predictive information. Taxonomy-only asks how much lineage alone explains. The combined model shows what happens when both are available.

THE STRESS TEST

What survives when lineage is removed?

Entire phyla are held out. This is deliberately harder: a model cannot simply recognize the lineage it saw during training.

Signal that persists

Sulfate reduction, sulfur reduction, Fe(III) reduction and fermentation retain useful environment-linked performance.

A result we should not overclaim

H₂ oxidation collapses under lineage control. Methanogenesis is not estimable because all 52 positives are Euryarchaeota.

A SECOND QUESTION

Can environment identify the organisms living at the hottest edge?

Yes, with strong held-out performance. But this is a classification of a terrestrial thermal niche—not evidence that an extraterrestrial environment contains life.
